# Культурный круг · Краснодонский МО

Веб-приложение для учреждения культуры. Позволяет публиковать события, регистрировать посетителей, создавать афиши и собирать пожелания аудитории.

## Запуск

Откройте `index.html` в современном браузере. Дополнительная установка не требуется.

Для запуска через локальный сервер можно использовать:

```powershell
npx serve .
```

## Возможности

- каталог и фильтрация событий;
- запись посетителей с контролем доступных мест;
- панель учреждения для добавления и удаления событий;
- встроенное редактирование опубликованных событий и основных текстов сайта;
- статистика регистраций и просмотр пожеланий;
- киноафиша кинозалов «Победа», «Родина» и «Мир» с формой заказа билета;
- генерация афиш в трех стилях и скачивание в PNG;
- форма обратной связи;
- разделы о Пушкинской карте, молодёжных вакансиях и целевом обучении;
- локальное хранение данных в браузере (`localStorage`).

Это автономный прототип. Для промышленного использования потребуется серверная часть, база данных, авторизация сотрудников и защищенная обработка персональных данных.
